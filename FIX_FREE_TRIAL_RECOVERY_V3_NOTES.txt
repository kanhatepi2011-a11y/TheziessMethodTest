FREE TRIAL ACTIVATION RECOVERY FIX (V3)
=======================================

What was fixed
--------------
1. Free-trial activation is now idempotent. If PostgreSQL already activated
   the trial but the browser lost the response, clicking the button again
   returns the same active trial instead of showing "already used".
2. Removed the dependency on ON CONFLICT(user_id), which failed on older Neon
   databases where free_trials existed without a matching unique constraint.
3. Replaced the advisory lock with a normal users-row transaction lock for
   better compatibility with pooled/serverless PostgreSQL connections.
4. The frontend now rechecks /api/auth/me after an interrupted activation and
   restores an active plan automatically.
5. A temporary /api/auth/me failure no longer deletes a subscription that was
   just successfully returned by the activation API.
6. app.js cache version was bumped so browsers receive the new logic.

Deploy
------
1. Upload/push this updated project to GitHub.
2. Redeploy it on Vercel.
3. Open /api/db-status and confirm:
   "ok": true
   "freeTrialsReady": true
   "schemaVersion": "free-trials-v3-idempotent"
4. Hard refresh the website with Ctrl+Shift+R, log in with Telegram, and press
   Start 3-Day Free Trial.
