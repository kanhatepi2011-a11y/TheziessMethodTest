FREE TRIAL DATABASE 42804 FIX (V4)
=================================

Problem
-------
PostgreSQL error 42804 means a datatype mismatch. Existing Neon databases may
have users.id as TEXT or UUID (often after CSV import), while the previous
runtime schema tried to create free_trials.user_id as BIGINT with a foreign key.
PostgreSQL rejected that incompatible relationship.

Fix
---
1. New dependent tables use TEXT user identifiers without runtime foreign keys.
2. Reads compare ids with ::TEXT so old BIGINT, INTEGER, UUID, and TEXT schemas
   all work.
3. INSERT values are still inferred from each existing column type.
4. UNION queries cast user_id to TEXT on both sides.
5. /api/db-status now reports the actual id types and schema version:
   free-trials-v4-type-compatible.

Deploy
------
Push this version to GitHub, redeploy the latest Vercel commit, then visit:
/api/db-status

- ok: true
- freeTrialsReady: true
- schemaVersion: free-trials-v4-type-compatible
