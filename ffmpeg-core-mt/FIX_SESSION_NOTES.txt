TELEGRAM SESSION FIX — 2026-07-27

This build fixes the case where Telegram authorization succeeds but the page
still shows “Telegram login required”.

Changes:
1. /api/auth/me now trusts the signed session cookie immediately and no longer
   logs the user out just because a database refresh temporarily fails.
2. The Telegram callback stores a safe browser-side copy of the public profile
   as a fallback before returning to the app.
3. The frontend retries the session endpoint after Telegram returns and uses
   the callback fallback when the cookie/API is temporarily unavailable.
4. The COOP/COEP service worker no longer intercepts /api/* authentication
   requests, preventing redirect and Set-Cookie interference.
5. Vercel HTTPS detection for Secure cookies is more reliable.
6. Logout clears both the server cookie and the browser fallback.
7. app.js has a cache-busting version query.

After deploying this build:
- Open the production Vercel URL.
- Press Ctrl+Shift+R once.
- Click Login with Telegram one more time so this new callback can save the
  corrected session/fallback.
