TheZiess Method — Telegram Admin Subscription Control V11

Security changes
- The public website can activate only the one-time FREE 3-day trial.
- POST /api/subscription/activate-demo rejects PRO, PREMIUM and MAX with
  ADMIN_ACTIVATION_REQUIRED.
- Paid plans are assigned only through Telegram commands from IDs configured
  in TELEGRAM_ADMIN_IDS.
- Admin grants do not create fake/demo payment records.

Telegram admin commands
- /grant TELEGRAM_ID pro
- /grant TELEGRAM_ID premium
- /grant TELEGRAM_ID max
- /grant @username pro
- /revoke TELEGRAM_ID
- /plans
- /user TELEGRAM_ID (then use the Grant/Revoke buttons)

Plan duration
- PRO: 30 days
- PREMIUM: 180 days
- MAX: 1 year (365 days)

Behavior
- Granting a paid plan replaces the user's current paid plan.
- Granting a paid plan cancels an active FREE trial so it cannot return later.
- The bot attempts to notify the user after a grant/revoke. Telegram may reject
  the notification when that user has never started the bot.
- The website refreshes subscription status when the user returns to the tab.
- The user must have logged in to the website with Telegram at least once so a
  database user record exists.
