POSTGRESQL 42703 FIX (V5)
==========================

Problem
-------
PostgreSQL code 42703 means undefined_column. The Neon database already had
older subscription/free_trials tables, but one or more required columns did
not exist. CREATE TABLE IF NOT EXISTS cannot repair an existing table.

Fix
---
This version creates isolated versioned tables:
- theziess_subscriptions_v5
- theziess_free_trials_v5
- theziess_payments_v5

It does not delete or ALTER the old tables. IDs are stored as TEXT user_key, so
BIGINT, UUID, INTEGER, or TEXT users.id values are supported.

Verification
------------
After deployment, open /api/db-status. It must return:
- ok: true
- freeTrialsReady: true
- subscriptionsReady: true
- paymentsReady: true
- schemaVersion: subscription-storage-v5-isolated
