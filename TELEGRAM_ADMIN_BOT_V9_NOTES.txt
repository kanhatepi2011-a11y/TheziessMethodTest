TheZiess Method - Telegram Admin Bot V9

Added:
- Secure Vercel Telegram webhook at /api/telegram/webhook.
- Protected setup endpoint at /api/telegram/setup.
- Admin-only commands: /admin, /stats, /users, /user, /subscriptions,
  /trials and /payments.
- /id command for finding the Telegram ID that must be added to
  TELEGRAM_ADMIN_IDS.
- Inline admin dashboard buttons and users pagination.
- Full user detail view with Telegram profile, registration, last login,
  current access, subscription history, payments and compression activity.
- Server-side compression event metadata logging. Video files and thumbnails
  are not uploaded to PostgreSQL.
- Webhook verification using X-Telegram-Bot-Api-Secret-Token.
