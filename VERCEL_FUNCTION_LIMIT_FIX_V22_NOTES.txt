THEZIESS METHOD — V22 Vercel Hobby Function Limit Fix

Problem
-------
Older project versions contained many JavaScript files under folders named "api".
When a new ZIP was copied over the old Git project, files removed from the ZIP
were not automatically deleted from the existing project. Vercel therefore
continued detecting more than 12 Serverless Functions.

V22 fix
-------
1. The only Vercel Function entrypoint is:
   api/[...route].js

2. Internal route handlers were moved from:
   server/api/
   to:
   server/routes/

3. vercel.json now configures only api/[...route].js.

4. .vercelignore excludes legacy API paths as a safety measure.

5. Run this once before committing:
   npm run cleanup-api

6. Commit deletions with:
   git add -A
   git commit -m "Fix Vercel Hobby function limit"
   git push origin main

Important
---------
Use "git add -A", not only "git add .", so Git records deletion of old API files.
After cleanup, this command must print only one file:

PowerShell:
Get-ChildItem api -Recurse -File

Expected:
api\[...route].js
