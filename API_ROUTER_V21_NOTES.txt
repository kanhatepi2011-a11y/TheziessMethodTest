THEZIESS METHOD — API ROUTER CONSOLIDATION V21

Problem fixed
-------------
V20 contained 25 JavaScript files inside the root /api directory. On Vercel,
each route file can be treated as a separate Serverless Function, exceeding the
requested function-file limit.

New structure
-------------
The root /api directory now contains exactly one Vercel Function:

  api/router.js

All existing route handlers and private helpers were moved without rewriting
their internal behavior to:

  server/api/

The catch-all router dispatches every existing public endpoint to its original
handler, including Telegram login, subscriptions, admin bot, TikTok checker,
TikTok OAuth, TikTok account management and TikTok Inbox/Draft uploads.

Public URLs did not change
--------------------------
Examples:

  /api/auth/telegram
  /api/auth/telegram/callback
  /api/auth/tiktok
  /api/auth/tiktok/callback
  /api/tiktok/account
  /api/tiktok/check
  /api/tiktok/upload/init
  /api/tiktok/upload/status
  /api/telegram/webhook
  /api/db-status

Vercel configuration
--------------------
vercel.json now applies maxDuration 30 to api/router.js.

Result
------
Root /api file count: 1
Requested maximum: fewer than 12
