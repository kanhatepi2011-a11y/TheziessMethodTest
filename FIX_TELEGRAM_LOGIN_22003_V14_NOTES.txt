TheZiess Method - Telegram Login PostgreSQL 22003 Fix V14

Problem
- Existing Neon `users.telegram_id` could be INTEGER.
- Some Telegram IDs exceed the INTEGER range, causing PostgreSQL error 22003.

Fix
- Added versioned table `theziess_users_v2`.
- Stores telegram_id as TEXT (no numeric overflow).
- All authentication, subscription, activity and admin queries use the new table.
- Best-effort migration preserves compatible legacy user IDs and subscriptions.
- Migration failure never blocks login.
