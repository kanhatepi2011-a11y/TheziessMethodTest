TheZiess Method - TikTok Video Checker V15

Added a fourth bottom-navigation item named Check between History and Profile.

The Check view accepts a public TikTok video link and displays:
- Resolution
- Overall bitrate
- Average FPS
- Duration
- File size

Implementation details:
- The browser sends the link to POST /api/tiktok/check.
- The API accepts only tiktok.com hosts and validates redirects.
- A valid Telegram login session is required.
- TikTok page metadata, official oEmbed metadata, media headers, and MP4 moov metadata are combined.
- The checker reads only small byte ranges when MP4 probing is necessary; it does not save the video.
- Private, deleted, region-restricted, age-restricted, or protected videos can return partial or unavailable values.
- The Vercel function is configured for a 30-second maximum duration.

No new environment variables are required.
