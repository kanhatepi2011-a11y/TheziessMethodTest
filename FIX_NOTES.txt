Telegram login fix
==================

Fixed the main issue shown in the screenshot:
- Added the missing click handler for the "Continue with Telegram" button.
- The button now opens /api/auth/telegram and starts the OIDC + PKCE flow.
- Added loading state and back-button recovery.
- Replaced the old hard-coded authorized domain with the current callback URL.
- Added TELEGRAM_CLIENT_ID, TELEGRAM_CLIENT_SECRET and TELEGRAM_REDIRECT_URI to .env.example.
- Corrected README setup: BotFather must allow both the production origin and /api/auth/telegram/callback.
- Added a safe redirect URI helper so local/current-host fallback works when TELEGRAM_REDIRECT_URI is omitted.
