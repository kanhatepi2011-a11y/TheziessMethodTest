FREE TRIAL ACTIVATION ERROR FIX
================================

Problem
-------
Clicking “Start 3-Day Free Trial” returned:
“Unable to activate subscription.”

Root cause
----------
The production PostgreSQL database was created with the original paid-only
schema. The old plan check constraints did not always permit the new FREE
plan, and a FREE activation also attempted to insert a fake $0 payment into
an older payments table. Any payment-schema mismatch rolled back the whole
subscription transaction.

Fix
---
1. Automatically migrates plan constraints by inspecting their definitions,
   not by assuming one exact constraint name.
2. Removes old paid-only constraints even when a newer FREE constraint also
   exists.
3. Does not create a payment record for the FREE trial.
4. Uses a PostgreSQL transaction lock so double-clicks cannot create two
   trials.
5. Enforces one FREE trial per Telegram account.
6. Retries schema initialization after a temporary database failure.
7. Returns clear messages for used trials and active subscriptions.

Deployment
----------
Push the project to GitHub and wait for Vercel to deploy. The first request
will run the safe migration automatically. The updated database.sql is also
included for manual execution in Neon if needed.
