TheZiess Method - Telegram Login Fix V13

Problem
- V12 executed ALTER TABLE ... SET NOT NULL inside ensureSchema().
- ensureSchema() runs before upserting a Telegram user.
- A DDL permission, table lock, or legacy-row problem therefore made every Telegram login fail.

Fix
- Removed the blocking ALTER TABLE operation from the login path.
- Paid-plan duration migration is now best-effort and can never reject authentication.
- New grants still use PRO 30 days, PREMIUM 180 days, and MAX 365 days.
- Old plan rows are upgraded when possible.
- OAuth state/PKCE cookies are cleared after a callback failure so retrying starts cleanly.
- Callback logs now include the actual safe database/error code for Vercel diagnostics.
