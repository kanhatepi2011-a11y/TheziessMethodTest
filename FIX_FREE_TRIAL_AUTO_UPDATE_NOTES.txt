THEZIESS METHOD — FREE TRIAL AUTO-UPDATE FIX

What changed
------------
1. Clicking "Start 3-Day Free Trial" now calls the activation API with cookies and no-cache enabled.
2. The button shows an "Activating Free Trial…" loading state and prevents duplicate clicks.
3. The returned active subscription is applied to the page immediately, so compression unlocks without a refresh.
4. The active subscription is also written into the signed HttpOnly session cookie on the server.
5. /api/auth/me can use the signed subscription as a safe fallback if a temporary database refresh fails.
6. The frontend rechecks the server session after activation without overwriting the successful activation response.

Expected result
---------------
After a logged-in Telegram user clicks "Start 3-Day Free Trial":
- the confirmation modal closes automatically;
- the plan status changes to FREE / Active;
- the expiry date shows 3 days from activation;
- the PATCH VIDEOS button becomes enabled immediately;
- the subscription remains active after refreshing the page.
